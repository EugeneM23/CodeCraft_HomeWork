# Шаг 89. Полотно — это программа: только мозг (14.11.2026)

**Зачем.** Пользователь открыл графы жителей деревни: мозга в них нет, а они работают — «граф притворяется, что
управляет, а под капотом идут процессы, которых не видно». Причина: мозг был слоем поверх старого движка
(автомат состояний: старт с первой ноды, стрелки между любыми нодами, рефлексы сенсоров `Detected` / `Lost`
«откуда угодно», вложенные состояния, флаг «начать заново»). Выбор пользователя: **удалить старую модель целиком**
(движок, тесты, пресеты, демо), потом пересобрать графы жителей на мозге и добавить групповое поведение — собрание
на площади по клавише, мэр в середине круга. Слово пользователя на всё: «делай всё до конца».

## Модель (что остаётся)

Персонаж делает только то, что нарисовано:

```
сенсоры ─(переменные)─► Brain ─► решения (приоритеты, «нельзя из») ─Do─► цепочка блоков ─► конец цепочки ─► Brain
```

1. **Граф** — невидимый корень с сенсорами (работают фоном, пишут переменные) и плоский список нод. Ровно один
   `Brain` (у отряда — `Squad Brain`).
2. **Старт — мозг.** Граф без мозга не работает: персонаж стоит, сенсоры молчат; на полотне и в инспекторе
   проблема `NoBrain`, в консоли — ошибка один раз.
3. **Стрелки — только четыре вида:** провод мозга к решению; `Do` решения — к первому блоку; выход блока по исходу
   (`Done` / `Failed` / «закончил», пронумерованные выходы `Random`); `On Tick`. Условий на стрелках, областей
   прерывания, приоритетов стрелок, «минимального времени» нет. Стрелка в ноду запускает её заново.
4. **Нода вне цепочки не работает никогда**: до неё не доходит ни одно `Do` (и ни одна цепочка `On Tick` такой
   ноды) — проблема `NotInChain`, полотно рисует её бледной.
5. **Нода — один блок.** Несколько задач в одной ноде (было у графов из кода) — проблема `TwoBlocks`.
6. **Мозг без провода `Target`** не слепнет целиком: решения, которым нужна цель (`Fight`, `Chase`…), не держатся
   («no target»), остальные (`Patrol`, `Daily Routine`, `Sleep`, `Follow Squad`, решения отряда) — держатся.
   Проблема `UnwiredPin` — только если к мозгу подключено решение, которому нужна цель (`ReasonerTask.NeedsTarget`).
7. **Правила мозга видны на его ноде** строкой: «решение держится ≥ 0,3 с · удар и умение не прерываются · цепочка,
   которая ничего не сделала, отдыхает 0,5 с».
8. `EnterState` (сохранения) — только мозг, решение или блок цепочки (блок отдаётся решению, чья это цепочка).

## Что удаляется

| Было | Почему уходит |
|---|---|
| старт с первой ноды, маркер `Start`, «Set as Start» | начало — мозг |
| рефлексы: `Detected` / `Lost` у сенсоров, «From anywhere», триггеры `VariableChanged`, `Signal`, область `Global` | решение в сенсоре — грабля №1 (§38); реагирует мозг приоритетами |
| стрелки по условию из обычных нод, фразы стрелок (`ArrowPhrases`) | развилка — `Branch` + `Compare` в цепочке |
| вложенные состояния, условия входа, области `Self` / `Branch` | граф плоский: мозг, решения, цепочки |
| `Restart When Finished` / `ReselectWhenComplete` | конец цепочки — всегда мозг |
| подмена подграфа ролью (`OverrideSubgraph`) | отряд меняет поведение решением `Follow Squad` (шаг 88) |
| композиты BT внутри ноды (`Sequence`, `Selector`, `Parallel`, `Repeat`, `Time Out`, `Cooldown`, `Inverter`, `Guard`, `Capability`, `Subgraph`, `Priority Select`, `Utility Select`, `Scored`, `Switch On`, `Random` потока) | спрятанное поддерево в ноде — то самое «под капотом» |
| ноды-код (`Code/Task`, `Code/Condition`) | на полотне их нет; блок — класс |
| условия, кроме тех, что входят в `Branch` (`Compare`, `AND` / `OR`, флаг, число) | были только для стрелок и условий входа |
| `GraphBuilder` | вместо него `BrainGraphBuilder` (мозг, решения, цепочки) |
| `Hear Calls` / `Call Memory` у каждого сенсора (скрытая галочка, по умолчанию вкл.) | сенсор-форма `Calls For Help` в `Detection` — видно, что персонаж слышит зов |

Старый ассет (рефлексы, вложенные ноды, условия на стрелках, неизвестные теперь типы) читается только для просмотра
и показывает проблему «построен по-старому» — его пересобирают.

## Новое для деревни и собрания

- **`Daily Routine`** (решение): держится всегда — распорядок дня, когда ничего важнее нет.
- **`Sleep`** (решение): держится, пока в его пине `Night` есть объект (провод от переменной сенсора `Time Of Day`).
- **`Go Inside`** (блок): дойти до двери (`Place`), войти — тело не видно и никому не мешает (`AICharacter.IsInside`,
  у `NavMesh Body` — последний в очереди расхождения) — `Duration` секунд (0 — пока решение не отпустит), выйти.
  Компонент стенда больше не прячет жителя по имени анимации.
- **`Calls For Help`** (сенсор-форма в `Detection`): «видит» то, о чём позвал союзник (`Call For Help`), `Remember`
  секунд, если это объект вида `Detection`.
- **Отряд:** решение **`Gather`** — держится, пока его пин `Called` (флаг доски) включён; блок **`Form Ring`** —
  `Middle` (кто стоит в середине: переменная с объектом члена отряда) и `Stand For` (сколько стоять, когда собрались;
  потом `Done`; 0 — пока решение не отпустит); **`Keep Formation`** — `Pace` (каким шагом идти к месту издалека);
  **`AI Squad`** — привязки переменных к объектам сцены (как у `AI Character`).

**Деревня.** 21 житель (20 и мэр). Граф каждого:

```
Detection ← Radius (Line Of Sight), Calls For Help ─► [Player] ─► Brain
Time Of Day ─► [Night]
Brain ─► Notice (1)        → Call For Help → Wait
      ─► Fight (2)         → Strike
      ─► Chase (3)         → Chase
      ─► Circle (4)        → Circle Target
      ─► Follow Squad (5)  → Keep Formation (шаг)
      ─► Sleep (6) ← Night → Go Inside (дом)
      ─► Daily Routine (7) → шаги дня по кругу (Perform / Chat / Go Inside)
```

**Командный граф `Town Meeting`** (объект `Town Meeting` с `AI Squad`, в нём все 21):

```
Squad Sight ─► [Foe] ─► Squad Brain ─► Gather (1) ← [Meeting Called]
                                         Do → Form Ring (вокруг [Meeting Place], в середине [Mayor], Stand For 10)
                                              Done → Set [Meeting Called] = false
```

Клавиша **M** (компонент стенда `LabTownBell` на объекте отряда) включает флаг `Meeting Called`. Мозг отряда берёт
`Gather`, кольцо ведёт строй, у жителей держится `Follow Squad` — все идут на площадь, становятся в круг лицом к
середине, мэр — в середине лицом туда, куда смотрит объект отряда. Собрались (90% на местах и мэр в середине — или прошло 30 с) — стоят 10 с,
флаг выключается, решение отпускает, жители возвращаются к своему дню (или ко сну).

## По учебнику

- §0.1 — пять слоёв: сенсор не решает, решение и исполнение — разные слои; §38 грабля №1 — «решение в сенсоре».
- §3.2 — один think-тик, фиксированный порядок, никаких наблюдателей вне активного пути: теперь порядок один —
  мозг, цепочка, надзор мозга. §3.4 говорит о рефлексах (3–5 на граф) — **расхождение**: рефлексов нет вовсе,
  реакцию «откуда угодно» даёт приоритет решения (`Notice`, `Fight`) раз в размышление (0,1 с), не посреди удара
  (§18.2). Причина — слово пользователя: всё, что управляет персонажем, — мозг.
- §32.2 — ассет не обещает поля, которое код не читает; здесь и обратное: код не делает того, чего нет в ассете.
- §10 — `Help` как сигнал шины: остаётся, но слышит его видимая форма сенсора.
- §20а — формация: кольцо слотов вокруг точки, слот — цель навигации; «строй не приоритет над выживанием» —
  `Notice` / `Fight` / `Chase` / `Circle` важнее `Follow Squad`. §21 — координатор: командный граф отряда.
- §24.1, B.6 «живой мир» — расписания и места, «меньше скрытых состояний»: уход в дом — видимый блок.
- §33.1 — в Play видно, что выбрано и почему (правила мозга — строкой на ноде).

## Тесты

Тесты на старую модель (рефлексы, вложенность, условия входа и стрелок, «начать заново», роли, композиты, ноды-код)
удаляются вместе с ней. Тесты нод переписываются на `BrainGraphBuilder` (решение → цепочка). Новые: граф без мозга
стоит; нода вне цепочки не запускается; стрелка в ту же ноду запускает её заново; старый ассет — только просмотр с
проблемой; мозг без провода `Target` берёт `Patrol`, но не `Fight`; `Daily Routine`, `Sleep`, `Go Inside`,
`Calls For Help`, `Gather`, `Form Ring` (`Middle`, `Stand For`), `Keep Formation` (`Pace`), привязки `AI Squad`.
PlayMode стенда: `VillageMeetingTests` — нажатие → все 21 в кругу у площади, мэр в середине → 10 с → расходятся.
