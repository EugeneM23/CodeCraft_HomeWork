## 2. Цели врагов — контракт с AI (главное)

Орда — Burst-симуляция без коллайдеров, пули её не видят. Чтобы пулемёт, турели, рикошет и авиаудар били и сущностей, и орду, вводим один вход:

```csharp
// Game, ключ GameContext: EnemyTargets. Реализация — моя (EnemyTargets), источники регистрирует AI.
public readonly struct EnemyRef            // кого бьём: сущность или монстр орды
{
    public readonly IEntity Entity;        // null у монстра орды
    public readonly int Source;            // индекс источника в EnemyTargets
    public readonly int Index;             // индекс в источнике
    public readonly int Version;           // защита от переиспользованного слота
}

public interface IEnemyTargetSource       // реализует AI для орды; сущности (EnemyFilter) — мой источник
{
    // Ближайший живой в радиусе. Без аллокаций.
    bool TryFindNearest(Vector3 from, float range, out int index, out int version, out Vector3 position);
    bool IsAlive(int index, int version);
    Vector3 GetPosition(int index);
    // Пуля прошла отрезок from→to толщиной radius: в кого попала первой.
    bool Raycast(Vector3 from, Vector3 to, float radius, out int index, out int version, out Vector3 point);
    void Damage(int index, int version, float damage, Vector3 hitPoint);
    // Урон по площади с падением к краю до minFactor. Вызывается моим кодом из каждого взрыва.
    void DamageArea(Vector3 center, float radius, float damage, float minFactor);
    // Число живых в круге — для авиаудара «по самой густой толпе».
    int CountInRadius(Vector3 center, float radius);
    int AliveCount { get; }
}

public interface IEnemyTargets            // этим пользуются оружие, навыки, AI-элиты не касается
{
    int Register(IEnemyTargetSource source); void Unregister(int source);
    bool TryFindNearest(Vector3 from, float range, out EnemyRef target, out Vector3 position);
    bool TryFindDensest(Vector3 from, float range, float clusterRadius, out Vector3 point);
    bool Raycast(Vector3 from, Vector3 to, float radius, out EnemyRef target, out Vector3 point);
    void Damage(in EnemyRef target, float damage, Vector3 hitPoint);
    void DamageArea(Vector3 center, float radius, float damage, float minFactor);
}
```

**Просьба к AI:**
- зарегистрировать источник орды (`IEnemyTargetSource`) в `GameContext.GetEnemyTargets()` при старте орды;
- урон орде от взрывов брать **только** через `DamageArea` (с уроном взрыва), а `ExplosionEvents.Exploded` оставить для отброса и слуха. Сейчас орда сама берёт 200 урона из `Exploded`; авиаудару навыка нужно 400, бронебойной пушке — 250. Я вызываю `DamageArea` из `ExplosionUseCase` и из авиаудара;
- до влития AI мой источник сущностей (`EnemyFilter`) работает сам, орда урона от пуль не получает.

## 3. Контракты для AI (запросы тимлида)

```csharp
// 1) Оглушение танка (прыжок элиты). Пока оглушён — не едет и не стреляет, башня стоит.
public static class TankStunUseCase
{
    public static void Stun(IEntity tank, float seconds);   // продлевает, не суммирует
    public static bool IsStunned(IEntity tank);
}
// событие для HUD/звука: CombatSignals.TankStunned(float seconds)

// 2) Давка элиты. AI ставит метку на враге-сущности:
//    CombatAPI.CrushBelowHealth : ValueKey<IEntity, IValue<float>>   // доля здоровья, 0.25
// TankCrushBehaviour давит такого врага, только если Health.GetPercent() <= метки (и скорость ≥ порога).

// 3) Выстрел пушки — для слуха элиты:
public static class CombatSignals
{
    public static event Action<Vector3, float> CannonFired;   // точка дула, GameTicks.Time
    public static event Action<float> TankStunned;
    public static event Action<Vector3, int> XpPicked;        // точка, сколько опыта (до влития звука)
    public static event Action<SkillId, int> SkillTaken;      // навык, новый уровень (до влития звука)
    public static event Action<Vector3, float> SmokeDeployed; // центр, радиус
}

// 4) Дым гранатомётов. Ключ GameContext: SmokeScreen.
public interface ISmokeScreen
{
    bool IsActive { get; }
    bool Contains(Vector3 point);                    // точка внутри облака
    bool BlocksLine(Vector3 from, Vector3 to);       // линия взгляда проходит через облако
}
```
Плевун и элита: если танк в дыму (`Contains(tankPos)`) или линия к нему закрыта (`BlocksLine`) — цель потеряна, идут к последней видимой точке. Это делает AI.

Звук: когда в `GameSignals` появятся `XpPicked(Vector3)` и `SkillTaken()`, поднимаю их вместо своих (или вместе со своими — HUD слушает `CombatSignals`).

## 5. Контракты с ядром (решено 2026-11-18)

Контракты ядра беру как есть (`App/Contracts/Run`, `App/Catalog`, `App/Run/RunAPI.cs`, коммит ядра `12fc0c6c0`).
- **Опыт:** зову `IRunService.AddExperience(n)` при подборе сгустка. Формулу, `LevelUp`, выбор 1 из 3 и паузу держит ядро. Эффекты навыков — по `SkillChanged(skill, level)`.
- **Гибель врага:** `GetEnemyDeaths().Died` → сгустки. Опыт за вид — моя таблица (GDD §5: Ползун 1, Плевун 3, Взрывун 3, элита 50, босс 300).
- **Шторка:** `ArenaLeft(n)` приходит до `ShutterChanged(true)` (~0.5 с) — по нему весь лежащий опыт летит в танк.
- **Гибель танка:** `EndRun(RunOutcome.Defeat)`.
- **Сборка:** `IMetaProgress` (`SelectedTank`, `GetInstalled`, `GetModuleLevel`) + `GameCatalog.FindTank` → `TankStatsUseCase` → применение на `RunStarted`. Числа модулей и навыков — мои `ModuleEffectConfig`/`SkillEffectConfig` по id; у ядра — id, имена, цены.
- **Без ядра** (песочница, тесты): если в GameContext нет `Run`, ставлю `LocalRunService` — замену с той же формулой, выбором 1 из 3 и отладочным экраном выбора; если нет `EnemyDeaths` — ставлю класс ядра `EnemyDeaths`.

## 7. Как устроено

**Автопулемёт.** `AutoGunBehaviour` на сущности оружия: раз в 0.1 с ищет цель (`EnemyTargets.TryFindNearest` от дула, 18 м), каждый тик поворачивает точку выстрела на цель (по горизонтали, вертикаль на центр цели), стреляет, когда кулдаун готов. При зажатом ПКМ цель — точка курсора на земле (`CursorUseCase`), стреляет туда без поиска. Пулемёт и турели — одна и та же логика. Пули: `BulletMoveBehaviour` в отрезке хода дополнительно спрашивает `EnemyTargets.Raycast` (орда), бьёт `Damage`.

**Опыт.** `XpOrbField` — пул до 512 сгустков 🔹 в массивах (позиция, значение, состояние), без GameObject; рисуется одним `Graphics.RenderMeshInstanced` (воксельный кубик 0.25 м, оранжевый эмиссив, покачивание). Падение: с гибели — 1–3 сгустка с разлётом. Танк в радиусе сбора → сгусток летит к танку (ускоряясь), в 0.6 м — начисление, `XpPicked`. Сгустки сливаются, если на арене их больше лимита (значение суммируется в ближайший). Перед шторкой — все разом летят и начисляются.

**Навыки.** Выбор — у ядра; по `SkillChanged` боевые системы пишут множители в `CombatModifiers` танка, оружие и применение статов их читают.

**Навыки (уровни 1→5).**

| Навык | Группа | Ур. 1 | Рост |
|---|---|---|---|
| Пулемётная турель | орудие | 1 турель на корме, 8 урона, 0.12 с, 18 м | ур. 2, 4: +20 % урона 🔹; ур. 3, 5: +1 турель |
| Авиаудар | орудие | бомба раз в 10 с по самой густой толпе в 30 м 🔹, 400 урона, воронка прототипа 4 м | −1 с; на 5-м — 2 бомбы |
| Рикошет | улучшение | снаряд пушки после взрыва отскакивает к ближайшему врагу в 15 м 🔹 вне радиуса взрыва, полный урон | +1 отскок |
| Скорострельность | улучшение | перезарядка пушки −12 % | −8 % (сумма: 12/20/28/36/44 %) |
| Броня | улучшение | +15 % макс. здоровья, лечит на прибавку | +15 % |
| Магнит | улучшение | радиус сбора +50 % | +30 % (50/80/110/140/170 %) |

Турели — маленькие коробки на корпусе (готовые точки крепления, до 3 шт.), сущности с `RangeWeaponInstaller`, прогрев при загрузке уровня. Авиаудар — публичный `VoxelAirStrike.Strike(point)` (сейчас `Explode` приватный; таймер прототипа выключается в забеге) + `EnemyTargets.DamageArea(point, 4, 400, 0.25)` + урон сущностям по площади.

**Модули (§6).** Уровень модуля = +15 % к двум главным параметрам за уровень.

| Модуль | Ур. 1 | Два параметра уровня 🔹 |
|---|---|---|
| 88-мм фугасная (штатная) | 150 урона, r 5, 2 с | урон, радиус |
| Бронебойная (1200) | 250 урона, пробивает 3 цели, r 2, 1.6 с | урон, перезарядка |
| Пулемёт MG (штатный) | 10 урона, 0.08 с, 2° | урон, темп |
| Броня штатная | +0 | здоровье (+15 % за уровень) |
| Экраны (1200) | +40 % здоровья, −8 % скорости | бонус здоровья, меньше штраф скорости |
| Двигатель штатный | 6 / 10.8 м/с | скорость, форсаж |
| Ходовая штатная | — | ширина давки, порог давки ниже |
| Дымовые гранатомёты (E, штатный) | облако 12 с, перезарядка 30 с | длительность, перезарядка |

Бронебойный снаряд: пробивает цели (сущности и орда через `Raycast`), взрыв в последней или в стене. Экраны видны на модели — коробки по бортам (простые боксы).

**Дым E.** `SmokeLauncherModule`: 6 облаков `VoxelSmoke.Deploy` по кругу 4 м + одно в центре 🔹, радиус покрытия ~7 м, 12 с. `SmokeScreen` хранит центры и время — `Contains`/`BlocksLine` — простая геометрия по кругам, без чтения вокселей.

**Применение сборки.** На `RunStarted`: `TankStatsUseCase.Compute` → `LoadoutApplyUseCase.Apply(tank, stats)` пишет здоровье, скорость, башню, урон/радиус/перезарядку пушки, пулемёт, спецмодуль; меняет снаряд для бронебойной. Навыки забега ложатся сверху через множители в `CombatModifiers` (на танке), чтобы модули и навыки не затирали друг друга.

## 8. Производительность

- Поиск цели — раз в 0.1 с на оружие, не каждый кадр; у орды — сетка AI (`HASH_CELL` 1.5 м).
- Сгустки — массивы и один instanced-вызов; ноль аллокаций в тике.
- Пулы: турели и бронебойные снаряды прогреваются в `CombatPoolPrewarm`.
- Маркеры: `Combat.AutoGun`, `Combat.XpOrbs`.
- `/perf-check`: сценарий «бой с ордой» — танк с 6 навыками на 3-м уровне, орда 60, 8 с; цель — 0 Б GC в тиках, PlayerLoop в бюджете.
