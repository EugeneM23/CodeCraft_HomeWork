# Танк Tank_01 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** танк на Playground, в который игрок садится по E: танковое управление, башня за курсором,
взрывная пушка, своё здоровье, водитель выживает при уничтожении танка.

**Architecture:** «вселение» — `PlayerContext.Character` переключается на сущность танка, и
существующие контроллеры (прицел, огонь, камера, тряска) работают на ней. Посадка/высадка —
`VehicleUseCase`, езда — `TankDriveBehaviour`, башня — `TurretAimBehaviour`, визуальная подвеска —
`HullSwayBehaviour`, гибель — `TankDestroyBehaviour`. Префаб и материалы собирает `TankBuilder`
(`Tools/Tank/Build`), он же ставит танк в Playground и расширяет маску взаимодействия персонажа.

**Tech Stack:** Unity 6000.0.38f1, Atomic Entities (методы ключей `EntityAPI` генерирует
`EntityAPIGenerator`), legacy `Input`, NUnit EditMode-тесты (`Game.Tests`).

Спек: `Docs/superpowers/specs/2026-11-06-tank-design.md`.

## Global Constraints

- Числа из спека: масса 3000, скорость 6 м/с, поворот 60°/с, разгон 6 м/с², торможение 12 м/с²,
  раскрутка поворота 360°/с², башня 90°/с, HP 400, перезарядка 2 с, снаряд 30 м/с / 2 с / урон 150 /
  радиус 5 м / минимум 0.25, качка ±4°, `maxDepenetrationVelocity` 1, маска взаимодействия 576.
- Все коллайдеры танка — на корневом GameObject (слой Character, 9): `Collider.TryGetEntity` ищет
  сущность только на объекте коллайдера.
- `FirePoint` — под неподвижным `TurretPivot`, не под качающимся `HullVisual`.
- `WeaponID.TankCannon` — в конец enum.
- Код не коммитится: в затрагиваемых файлах (`EntityAPI.cs`, `[Character].prefab`, `Playground.unity`,
  `CharacterSystemInstaller.cs`, …) лежат незакоммиченные правки пользователя. Коммитятся только
  новые документы.
- `autoRefresh` в редакторе выключен: после записи файлов — `AssetDatabase.Refresh()` и перекомпиляция.
- Playground-персонаж распакован из префаба: изменения `[Character].prefab` до сцены не доходят,
  сцену билдер правит отдельно.
- `AddValue` бросает на повторный ключ: `Transform` и прочие ключи танка добавляет только `TankInstaller`.

  - `TryExit_FirstFreePointWins` — первая точка занята, вторая свободна.
  - `Eject_AllPointsBlocked_PutsDriverAboveVehicle`.
