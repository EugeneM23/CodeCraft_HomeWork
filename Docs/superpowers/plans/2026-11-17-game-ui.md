# План: интерфейсы игры

**Дата:** 2026-11-17
**Спецификация:** `Docs/superpowers/specs/2026-11-17-game-ui.md`
**Ветка:** `game/ui`

Задачи 2–4 пишутся субагентами параллельно, только код (без редактора). Компиляцию, сборку префабов и проверку в редакторе делает сессия команды по очереди.

## 1. Основа (последовательно, первой)

- `Assets/Modules/ScreenStack` — копия `module/ScreenStack@b5be2183`.
- `Game.asmdef`: ссылки `Unity.InputSystem`, `ScreenStack`. `Game.Tests.asmdef`: те же.
- Ввод: `Assets/Game/Configs/Input/GameControls.inputactions` (карты `Tank`, `UI`, `Sandbox`), класс `GameControls` в `Scripts/Shared/Input/`. `IGameInput` + `GameInput` (один экземпляр, загрузка переопределений).
- `Scripts/UI/Services/`: `IGameFlow`, `IPauseService`, `ISettingsStore`, `IPlayerProgress`, `IAudioVolumes`, `IUiSounds`, `IBattleStats`, `IBattleResultSource`; `Scripts/UI/Stubs/` — заглушки; `UiServices` — временная точка доступа до AppContext.
- Данные: `GameSettings`, `SettingsApplyUseCase`, `TankSlot`, `TankStats`, `LevelConfig`, `LevelCatalogConfig`, `TankModuleConfig`, `ShopCatalogConfig`, `TankLoadoutUseCase`, `ShopUseCase`, `PlayerProgressData`.
- Стиль и сборка: `UiStyle` (рантайм, цвета и размеры), `UiFactory` (редактор: панель, текст, кнопка, слайдер, переключатель, выпадающий список, список с прокруткой), шрифты Roboto SDF.

## 2. Меню (субагент)

`MainMenuScreen`, `LevelSelectScreen`, `HangarScreen`, `ShopScreen`, `ConfirmDialog`, `CurrencyBar`, `MenuFlow`; сборщик `MenuUiBuilder` → `Prefabs/UI/MenuUi.prefab`; сцена `Scenes/MainMenu.unity`.

## 3. Настройки и переназначение (субагент)

`SettingsScreen` (вкладки), `GraphicsSettingsTab`, `AudioSettingsTab`, `ControlsSettingsTab`, `RebindRow`, `RebindOverlay`; сборщик `SettingsScreenBuilder` → `Prefabs/UI/SettingsScreen.prefab` (вкладывается и в меню, и в бой).

## 4. Бой (субагент)

`HudScreen` (прочность, броня, перезарядка, МГ, прицел, счётчики, подсказки, отладка), `PauseScreen`, `BattleResultsScreen`, `BattleFlow`, `SandboxBattleStats`; сборщик `BattleUiBuilder` → `Prefabs/UI/BattleUi.prefab`.

## 5. Интеграция (сессия команды)

Компиляция, сборка префабов, сцена меню, `BattleUi` в копии VoxelSandbox, снятие `VoxelDemoHud`, перевод управления танком на `IGameInput` (после влития чистки), тесты EditMode/PlayMode, скриншоты, ревью, `/perf-check`, отчёт тимлиду.
