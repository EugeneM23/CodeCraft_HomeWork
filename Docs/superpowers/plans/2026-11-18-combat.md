# Боевые системы, веха 1 — план реализации

Спецификация: `Docs/superpowers/specs/2026-11-18-combat.md`. Ветка `claude/combat-326ad2`.

## Шаг 0 — фундамент (сделан тимлидом команды)

`Assets/Game/Scripts/Features/Combat/`:
- `Contracts/` — интерфейсы для меню, AI, ядра: `IEnemyTargets`, `IEnemyTargetSource`, `EnemyRef`, `ISmokeScreen`, `ISkillDraft`, `SkillOffer`, `SkillGroup`, `IRunSkills`, `ISpecialModule`, `TankStats`, `ModuleLevel`, `CombatModifiers`, `ICombatRun`, `EnemyDeath`.
- `Stubs/` — `SkillId`, `ModuleId`, `TankId`, `EnemyKind` до контрактов ядра.
- `CombatAPI.cs` (ключи сущностей), `CombatContextAPI.cs` (ключи GameContext), `CombatSignals.cs`, `CombatConfig.cs` (Resources, иначе умолчания кода).
- `CombatBehaviour.cs` — поведение GameContext (добавлено в `GameContextInstaller`): ставит сервисы и цепляет части к танку игрока через три `*Setup` (`InstallContext/UninstallContext/AttachTank/DetachTank`).
