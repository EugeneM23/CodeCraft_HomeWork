# Гранаты — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** игрок кидает гранаты по Q в точку курсора; граната отскакивает и через 2 с взрывается взрывом ракеты.

**Architecture:** запас гранат и бросок живут на персонаже (`CharacterGrenadeInstaller`), ввод — в контексте
игрока (`CharacterGrenadeController`). Граната — пуловая сущность с Rigidbody, `GrenadeInstaller` +
существующий `ExplosionInstaller`; по запалу вызывается `ExplosionUseCase.Explode`. Префабы, пикап и
подключение к `[Character]` собирает редакторский `GrenadeBuilder` (меню `Tools/Grenades/Build`), как
`RocketFxBuilder`/`RegaxPrefabBuilder`.

**Tech Stack:** Unity 6000.0.38f1, Atomic Entities (ключи `EntityAPI` → методы генерирует `EntityAPIGenerator`),
RayFire, legacy `Input`.

Спек: `Docs/superpowers/specs/2026-11-05-grenades-design.md`.

## Global Constraints

- Числа по умолчанию — из спека: 3 гранаты, Q, кулдаун 0.8 с, дальность 15 м, 12 м/с, мин. полёт 0.6 с,
  запал 2 с, урон 80, радиус 5, мин. урон 0.25, пикап +2.
- Тесты отложены по решению пользователя (`GrenadeTrajectoryTests` — позже). `GrenadeTrajectory`
  остаётся чистой статической функцией без Unity-состояния, кроме `Vector3`/`Mathf`.
- Коммитов не делать без просьбы пользователя.
- Установщик работает, только если он в `MonoEntity.sceneInstallers`; простого `AddComponent` мало.
- `autoRefresh` в редакторе выключен: после записи файлов — `AssetDatabase.Refresh()` и перекомпиляция.

- [ ] Добавить в `EntityAPI` раздел `#region Grenades` с пятью `ValueKey`.
- [ ] Написать `GrenadeTrajectory`:

```csharp
public static Vector3 ClampToRange(Vector3 from, Vector3 to, float maxRange)
{
    Vector3 flat = new Vector3(to.x - from.x, 0f, to.z - from.z);
    if (flat.sqrMagnitude <= maxRange * maxRange) return to;
    flat = flat.normalized * maxRange;
    return new Vector3(from.x + flat.x, to.y, from.z + flat.z);
}

public static Vector3 GetLaunchVelocity(Vector3 from, Vector3 to, float throwSpeed, float minFlightTime, Vector3 gravity)
{
    Vector3 delta = to - from;
    Vector3 flat = new Vector3(delta.x, 0f, delta.z);
    float time = Mathf.Max(flat.magnitude / Mathf.Max(throwSpeed, 0.01f), Mathf.Max(minFlightTime, 0.01f));
    Vector3 velocity = flat / time;
    velocity.y = delta.y / time - 0.5f * gravity.y * time;
    return velocity;
}
```

### Task 2: Граната и запал

**Files:** Create `GrenadeInstaller.cs`, `GrenadeFuseBehaviour.cs`.

**Consumes:** `GrenadeFuse`, `ExplosionUseCase.Explode(IEntity, Vector3, Collider, GameFactory)`,
`SpawnUseCase.UnSpawnEntity(GameFactory, IEntity)`.

- [ ] `GrenadeInstaller` (`_damage = 80`, `_fuse = 2f`, `_rigidbody`): `EntityID` (имя без `(Clone)`),
  `GameObject`, `Transform`, `RiggedBody`, `Damage = new ReactiveInt(_damage)`,
  `GrenadeFuse = new CooldownTimer(_fuse)`, `AddBehaviour<GrenadeFuseBehaviour>()`.
- [ ] `GrenadeFuseBehaviour : IEntityInit, IEntityTick`: в `Tick` тикает запал; истёк → `Explode` в
  `transform.position` с `hit: null`, затем `UnSpawnEntity`. Таймер новой гранаты стартует с 0 (истёкшим),
  поэтому взрыв только если граната активна и брошена — `GrenadeThrowAction` сбрасывает запал сразу
  после `Create`, до первого тика.
