# Звук игры: куда класть клипы

Вся настройка звука уже сделана. Ваша часть — положить файл в папку ключа.

## Как подставить звук

1. Найдите ключ в таблицах ниже, например `tank.engine_loop` — петля двигателя.
2. Положите один или несколько файлов (`.wav`, `.ogg`, `.mp3`) в папку `Assets/Game/Audio/Clips/tank/engine_loop/`.
   - Один файл — играет он.
   - Несколько файлов — каждый раз случайный, без повтора подряд (шаги, выстрелы, рык).
3. Всё. Unity сама:
   - поставит настройки импорта: короткие звуки — в память и заранее, музыка — потоком с диска;
   - подставит файлы в событие ключа.

   Если подстановка не сработала (например, файлы положены при закрытом редакторе), нажмите **Tools → Audio → Sync Banks**.

Имена файлов любые. По правилам проекта — латиница, без пробелов и скобок: `Tank_Engine_Loop_01.wav`.

Чтобы вернуть старый звук или тишину, удалите файлы из папки и нажмите **Sync Banks**. В README.txt внутри каждой папки написано, чей это ключ, — его не удаляйте.

## Как прослушать

- **Без запуска игры:** **Tools → Audio → Sound Board**.
  - Показывает все банки и ключи и клипы каждого ключа.
  - ▶ проигрывает клип.
  - Красная пометка — у ключа нет клипа, он молчит.
  - Кнопка открывает папку ключа.
- **В игре:**
  - Откройте `VoxelSandbox`, нажмите Play.
  - В иерархии найдите объект `GameAudio(Clone)` и его компонент `Audio System`. Кнопка `PlayEvent` с ключом, например `tank.hit`, проигрывает звук.
  - При входе в Play в консоли — по одному предупреждению на каждый ключ без клипа.

## Громкость, высота, 3D

Это настроено в ассете события `Assets/Game/Audio/Events/<банк>/<банк>_<ключ>.asset`:
- громкость и разброс высоты;
- 2D или 3D, дальность слышимости;
- петля;
- канал громкости.

Синхронизация меняет в событии только клипы, ваши правки остальных полей сохраняются. Клип, перетащенный в событие вручную (не из `Clips/`), при пустой папке ключа тоже остаётся. Записи банка и параметры, добавленные вручную, синхронизация не удаляет. Если клип громче или тише остальных, поправьте `Volume` в этом ассете.

## Каналы громкости (ползунки меню «Звук»)

| Ползунок | Группа микшера `Assets/Game/Audio/AudioMixer.mixer` | Что в ней |
|---|---|---|
| Общая | `Master` | всё |
| Музыка | `Music` | музыка меню и боя, победа и поражение |
| Эффекты | `Effects` | танк, оружие, разрушение, монстры, орда |
| Интерфейс | `UI` | кнопки и экраны |
| Окружение | `Ambient` | ветер, дождь, гром |

### Музыка

| Папка | Когда |
|---|---|
| `Clips/music/menu/` | главное меню, треки по порядку по кругу |
| `Clips/music/hangar/` | ангар и выбор главы, по кругу. Пока пусто — играет меню |
| `Clips/music/battle_calm/` | бой, слой «спокойно»: звучит всегда |
| `Clips/music/battle_horde/` | бой, слой «орда»: нарастает с числом живых монстров |
| `Clips/music/battle_peak/` | бой, слой «пик»: вступает, когда монстров почти предел |
| `Clips/music/elite/` | пока жива элита, по кругу. Пока пусто — слои боя держатся на пике |
| `Clips/music/battle/` | бой без слоёв, треки в случайном порядке |

**Слои боя.** В каждую из трёх папок `battle_*` кладётся один трек. Все три одной длины и одного темпа, сведённые так, чтобы звучать вместе: игра запускает их одновременно и петлёй, меняя только громкость слоёв. Если в слоях нет ни одного трека, бой играет папку `battle/` как раньше.

Пока папки пустые, играет `Assets/Game/Audio/Music/Music.wav` (если треки не положены в каталог `Assets/Game/Audio/Music/MenuMusic.asset` / `BattleMusic.asset` вручную — их синхронизация не трогает). Музыка меню включается в любой сцене без `GameContext`, музыка боя — на уровне и выключается, когда уровень выгружается.

## Новый звук, которого нет в таблицах

Новый ключ добавляется в код:
- в `Assets/Game/Audio/Scripts/AudioKeys.cs` и `AudioLayout.cs`;
- в то место игры, где он должен звучать.

Это работа программиста, напишите, что и когда должно звучать.

## Для программистов

- Спецификация — `Docs/superpowers/specs/2026-11-17-game-audio.md`.
- Модуль — `Assets/Modules/AudioEngine/README.md`.
- Проиграть звук из кода — `GameAudio.Play(AudioKeys.Tank.HIT, position)`.
- Сигналы без сущности — `GameSignals`, `VoxelSignals`.
- Проверка настройки — **Tools → Audio → Validate**.
