# Зомби на танке: как подключить анимации

> **Выключено с 2026-11-20** по слову пользователя («пусть уберут опцию для зомби залезать на танк, потом добавим»): `HordeRiderOptions.LeapOntoTank = false`, зомби не прыгают на танк и бьют его с земли (`Docs/Game/ZombieChase.md`). Код и тесты остались (тесты включают прыжки на себя); вернуть — поставить `true`.

## Что происходит

Ползун орды рядом с корпусом (зазор ≤ 2.2 м) может запрыгнуть на танк. Чаще всего — когда танк медленный (≤ 3 м/с: шанс 0.9 в секунду). На скорости шанс в 7 раз меньше, выше 9 м/с не прыгают совсем. На танк, который резко поворачивает (рыскание выше 0.8 рад/с), тоже не прыгают. Прыгают по одному, не чаще раза в 0.35 с.

Точек хвата шесть, на каждой один зомби (`HordeAttachPoint`):

| Точка | Где | Куда смотрит |
|---|---|---|
| `FrontLeft`, `FrontRight` | передняя палуба | назад, на башню |
| `Left`, `Right` | надгусеничные полки | внутрь, к центру |
| `Rear` | корма | вперёд |
| `Turret` | крыша башни | по стволу, крутится с башней |

Высота точек измеряется лучами по коллайдерам танка при привязке. Зомби стоит ногами на броне.

## Состояния (`HordeRiderState`)

```
None ──прыжок──▶ Leaping ──долетел──▶ Clinging ──0.35 с──▶ Tearing ──┐
                    │                    │                            │ удар каждые ~0.8 с (Struck)
                    └────────────────────┴──── хватка = 0 ────────────┴──▶ ShakenOff ──упал──▶ None
смерть в любом состоянии ──▶ Died
```

- **Leaping** — летит дугой к точке, точка едет вместе с танком.
- **Clinging** — приземлился и хватается.
- **Tearing** — рвёт броню. Удар — 5 урона (× масштаб урона зомби × `riders.damageScale`), идёт в здоровье танка вместе с укусами орды.
- **ShakenOff** — сорвался, падает с инерцией танка, отлетает от корпуса. На земле снова идёт с ордой. 3 с не прыгает повторно.

**Хватка** (`Grip`, 1 → 0) тратится от:
- резкого поворота: рыскание выше 0.8 рад/с (у Tiger полный поворот — 1.36 рад/с, сбрасывает примерно за секунду; на башне считается и поворот башни);
- скорости выше 8 м/с;
- рывка: таран стены, резкая остановка (ускорение выше 14 м/с²);
- попадания: пулемёт или пушка самого танка, взрыв — минус 0.45 за попадание.

В спокойной езде хватка восстанавливается.

**Смерть на броне** идёт обычным путём орды: события, награда, гибы. Труп кладётся на землю у борта, а не висит в воздухе. Брызги летят с места хвата и пачкают броню (`TankBloodStains.Splat`).

Все числа — `HordeOptions.riders.settings` (`HordeRidingSettings`) в инспекторе `HordeInstaller`. Какие виды прыгают — `riders.kindMask` (по умолчанию только ползун).

## Как подключить свои анимации

### 1. Клипы VAT (самое простое)

Зомби орды рисуются VAT-шейдером. Новую анимацию «рвёт танк» запечь так же, как run, attack и idle (`Tools/Horde/Bake Zombie VAT`, `HordeVatBaker`). Получится `HordeClip` (`start`, `count`, `frameRate`, `loop`). Его ставят в инспекторе:

| Поле `HordeOptions.riders` | Состояние | Заглушка сейчас |
|---|---|---|
| `leapClip` | Leaping | run |
| `clingClip` | Clinging | idle |
| `tearClip` | Tearing | attack |
| `fallClip` | ShakenOff | idle |

Пустой клип (`count = 0`) — значит заглушка.

### 2. Свой аниматор (полный контроль)

```csharp
public sealed class ZombieRiderAnimator : IHordeRiderAnimator
{
    public void Pose(in HordeRiderInfo rider, ref HordeRiderPose pose)
    {
        // rider.State, rider.Point, rider.StateTime, rider.Grip — что делает и где держится.
        // Можно сдвинуть ноги (присесть, свеситься с борта), повернуть, выбрать свой клип и время в нём.
        if (rider.State == HordeRiderState.Tearing && rider.Point == HordeAttachPoint.Left)
            pose.Clip = _tearSideClip;
    }
}

HordeRiderEvents.Animator = new ZombieRiderAnimator(); // null — вернуть заглушки
```

Вызывается раз в кадр на каждого зомби перед отрисовкой, в главном потоке. Внутри нельзя выделять память.

### 3. События (звук, эффекты, крупные анимации на GameObject)

```csharp
HordeRiderEvents.StateChanged += info => { /* info.Previous → info.State, info.Point, info.Cause */ };
HordeRiderEvents.Struck += info => { /* удар по броне: info.Damage, info.Feet */ };
HordeRiderEvents.Died += info => { /* убит на броне */ };
```

`HordeRiderInfo.Slot` и `Version` — тот же хэндл, что у боевой системы (`IEnemyTargetSource`). Опрос без событий: `HordeBehaviour.Riders.Count`, `GetRider(n)`, `TryGetRiderOf(slot, out info)`.

Если анимация «разрывания» должна быть на скелетном GameObject, а не VAT: на `StateChanged → Tearing` поставить из пула скелетную модель в `info.Feet`, а VAT-зомби спрятать своим аниматором (`pose.Feet` под землю). На `ShakenOff` и `Died` — вернуть.

## Ограничения

- Наклон тела не задать: VAT-инстанс хранит только позицию и рыскание. Поза «висит на борту» — это клип или сдвиг ног.
- Песочные `Zombie.prefab` не прыгают: это не орда. Они бегут к танку и кусают его с земли (`Docs/Game/ZombieChase.md`).
- Верхом не больше 6 зомби на танк, по одному на точку.

## Живые зомби в песочнице

При загрузке `VoxelSandbox` код сам создаёт `[SandboxHorde]` — настоящую VAT-орду с наездниками (`SandboxHorde.cs`, настройки в `Assets/Game/Resources/SandboxHordeConfig.asset`). Сцену править не нужно.

- Группа из 20 ползунов вылезает из земли на траве у (−16, 14): 18 м от старта танка, впереди-слева. Через 12 с после того, как группу перебили, приходит новая.
- Урон орды по танку в песочнице ×0.25: иначе 6 наездников и толпа убивают Tiger (1000 HP) меньше чем за 10 с, и забег кончается.
- Забег режиссёра арены сдвигает навигационную сетку на 40×40 в центре, и старт танка (x −34) оказывается вне сетки. Песочная орда возвращает сетку на всю карту (−40…40).
- F2 → «Враги»: «Активные зомби в песочнице» (вкл/выкл; выключение убирает орду без смертей и опыта), «Размер группы» 5…40, кнопки «Группа сейчас» и «Убрать всех».
- Если в сцене уже есть орда (тест, стенд), песочная не создаётся. Тесты, которые ставят свою орду, сначала удаляют все `HordeInstaller`.
